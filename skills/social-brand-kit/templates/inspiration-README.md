# inspiration/

Drop references here: screenshots of posts, covers, Reels frames and palettes
you like — especially ones you know performed well. Describe each one in
`notes.md` (what to borrow, what not to). `content-ideas` analyzes the
patterns; `social-visuals` uses the visual ones.

- `viral/` — high-performing references from other creators. Private: this
  folder is gitignored by default (others' content). Never republish.
- Prefer 6–10 well-chosen references over 50 random ones.
- For video, add 3–6 frames (screenshots) plus the caption/transcript — Claude
  can't watch video or hear audio.

Always record: the link (if any), the format, why you think it worked, and the
metrics you could see (views/likes/comments), with the date.
