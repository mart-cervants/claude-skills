# Monthly calendar template

Produce the month as ONE table, show it to the user, and only then draft full
copy. Dates and times in the time zone from the kit's `brand-profile.md`.

## Planning table (step 3 of the workflow)

| # | Date / time | Pillar | Format | Raw idea (source) | Hook (≤125 chars) | CTA | Visual | Status |
|---|---|---|---|---|---|---|---|---|
| 1 | Tue 3 Dec, 9:30 | Educational | Image card | (idea ID 4 from the backlog) | (hook in the brand's language) | Book a call | Brand card | planned |

Rules:
- 12–16 posts per month; no more than 1 promotional post per week.
- Spread pillars; don't put two promotional posts in a row.
- Mark each post's format: image card, carousel, Reel/video, text only.
- Vary hook styles (question, statement, number the user supplied).
- Don't schedule on days the user marks unavailable to reply to comments.

## Approval table (step 7)

Same rows, with full copy:

| Date | Pillar | Full text | Visual file | CTA | Anti-slop gate |
|---|---|---|---|---|---|

Keep the visual file name consistent: `YYYY-MM-DD-slug.png` (the same name used
for hosting under the brand's own site if public URLs are needed).

## Optional: CSV for bulk import

Metricool supports CSV import for batch scheduling. If the MCP path fails,
export the approved table to CSV in the format Metricool's batch-import
template asks for (check Metricool's current template; columns change).
